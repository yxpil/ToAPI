# ToAPI — 测试与质量规范

## 1. 测试金字塔（针对 ToAPI 自身）

| 层 | 工具 | 覆盖目标 |
|---|---|---|
| 单元测试 | Vitest | VarResolver 插值、提取器、UA 预设、Repo 层 SQL、脚本桥接函数 |
| 集成测试 | Vitest + 本地 HTTP 靶场（`@usehttp/node` 或自建 express） | HttpEngine：代理、重定向、CookieJar、超时、伪装 Header 真实落线 |
| 沙箱测试 | Vitest + worker/vm | 熔断生效、禁全局生效、子请求深度限制、`pm.*` 兼容层 |
| E2E | Playwright Electron | 黄金路径：建项目→建接口→发送→断言→跑 Runner→看报告 |

**硬规则**：HTTP 引擎的集成测试必须打真实本地 HTTP 服务，禁止 mock undici —— 伪装 Header 顺序、代理隧道这类行为只有真发请求才能验证。

## 2. 关键测试用例清单

### 2.1 变量与插值
- `{{var}}` 在 URL / Params / Headers / Body / 脚本内 `toapi.vars.get` 五处行为一致
- 查找顺序：运行时 > 环境 > 全局；同名覆盖正确
- 未命中变量保留原文并高亮警告，发送结果中可见
- 循环引用（a={{b}}, b={{a}}）检测并报错，不死循环

### 2.2 伪装
- UA 预设替换后请求线真实携带（集成测试断言靶场收到的 UA）
- 伪装 Header 覆盖默认 Header，大小写与顺序可控
- 代理开启后请求经代理（靶场 + 本地代理双计数）
- CookieJar：登录子请求种 cookie，主请求自动携带；`inherit`/`isolated`/`disabled` 三态正确
- `ignoreTlsErrors` 仅当前请求生效，不污染全局

### 2.3 脚本沙箱
- `toapi.request.send` 可发子请求且写入历史（`isSubRequest=true`）
- 脚本内 `fetch`/`require`/`process` 不可达
- 死循环脚本 5s 熔断，主请求标记 `SCRIPT_TIMEOUT`，应用不卡死
- 子请求深度 >8 抛错；总数 >50 抛错
- pre_script 中 `skip()` 后请求不发出，状态 SKIPPED
- post_script 异常不影响响应展示（断言标失败，响应正常入库）

### 2.4 链式与 Runner
- 提取器 jsonpath/regex 命中与未命中（未命中 + stopOnExtractFail=true 时中止）
- Runner 串行顺序 = sort_order；stopOnFail 语义正确
- 运行时变量跨接口传递，Runner 结束后不泄漏到下一次运行
- 取消：正在飞的请求 abort，队列不再继续

### 2.5 数据层
- 迁移从 v1 顺序升到最新，各版本样本库均可打开
- 级联删除：删项目清集合/接口/环境，历史 api_id 置 NULL 但保留
- 大 body（>256KB）落文件，history:list 不加载 body 字段
- 游标分页在连续写入下不重不漏

### 2.6 TAPI 与代码转换
- 导出→导入**往返等价**：项目树、脚本、提取器、伪装配置逐项一致；ID 全部重新生成不冲突
- 敏感变量导出模式：`strip` 值必为空且 `redacted=true`，导入后留空占位并保留 `secret` 标记由 UI 提示补填；`plain` 文件头含 `contains_secrets` 标记且值可还原；`encrypt` 尚未实现（08 号文档 §9），不写用例
- checksum 篡改检测：改 payload 任一字节后**拒绝导入且库内无残留**；旧文件缺 checksum 降级为跳过校验
- format_version：高于本应用支持范围明确拒绝（提示升级）
- 冲突策略：新建（同名项目自动加「(2)」）/ 合并（同名集合按名称合并、接口按「方法+URL+名称」判重，跳过 / 覆盖 / 保留两份），全局变量同名不覆盖本地值
- 落地用例：`tests/unit/tapi/format.test.ts`（7 例：规范化 JSON 键序与数组保序、哈希稳定性、字段改动敏感性）与 `tests/integration/tapi/roundtrip.test.ts`（17 例，真实库：导出结构比对、剔除与明文两种携带、子树导出、历史/Runner 不入文件、inspect 计数与不写库、导入还原集合认证与脚本、判重三策略、overwrite 覆盖字段、校验和篡改拒绝、非 `.tapi`/非法 JSON/坏 targetProjectId 报错且无残留、无对话框与坏目录导出报错）
- `api → code → api` 往返快照：cURL/JS/Python 三方向，method/URL/headers/body 语义一致
- 响应转断言：三路合并不覆盖用户已改断言，增量新增
- Python 案例：子进程超时被 watchdog 强杀；`case.request.send` 经桥接层与 JS 共享代理/CookieJar（靶场双侧验证）；子请求深度限制生效

### 2.7 MD 文档解读与文档内测试
- 解读：五类识别规则各有正负用例；低置信度草稿默认不勾选；参数表不猜类型
- 解析：frontmatter 缺失/非法版本报错；`depends` 成环检测拒绝运行；未知指令警告不中断
- 运行：拓扑顺序正确；`[extract]` → 下游 `{{var}}` 引用链路通；断言失败下游 SKIPPED
- 同步：`.tapi.md → App → .tapi.md` 往返等价快照；外部改文件后 sync_state 流转正确；覆盖导出有确认弹窗
- 安全：MD 内 `[script]` 块与接口脚本同沙箱同熔断；MD 渲染白名单防 HTML 注入（`<script>`/事件属性剥离）
- 图标：全界面扫描无 emoji 字符；状态标记/树图标/Toast 均为内联 SVG（e2e 断言渲染产物中无 emoji codepoint）

### 2.8 开放通道（Local API / MCP / Skill）
- 认证：未设密码时开关无效、弱口令（<8 位）被拒；无 token / 错误 token 一律 401；清除密码即关闭通道；任何返回值与日志都不含密码明文
- 限流：达到 `ratePerMin` 触发 429 + `RATE_LIMIT`，调高后立即恢复
- 闸门：host 白名单外的 `send/run` 在无界面模式直接 403；未授权客户端首次连接走授权条
- MCP：`initialize → tools/list → tools/call`；错密码是 `isError` 而非协议错误；未知工具与非法入参同样降级为工具级错误；通知（无 id）不回包；HTTP 传输与 stdio 行为一致
- 脱敏：secret 变量经任何通道（MCP 返回、HTTP 响应含靶场回显的请求头、`.tapi` 导出、环境变量、审计摘要）均不出明文
- 入参校验：未知字段、类型不符、超长、枚举外的取值一律 `VALIDATION`（`tests/unit/open/params.test.ts`，6 例）
- Skill：`SKILL.md` frontmatter 合规、只列敏感变量名不给值、附 cURL/JS/Python 示例清单
- 审计：每次外部调用有 `external_call_log` 记录（含失败），标注通道与客户端
- 落地用例：`tests/integration/open/channels.test.ts`（18 例，真实监听端口 + 真实靶场）、`tests/unit/open/params.test.ts`（6 例）
- 尚未覆盖（对应功能未实现）：Runner 并发排队与 `BUSY`、Skill 包写盘与示例在 CI 真跑、MCP SSE 流式（11 号文档 §9）
