# ToAPI — UI 设计规范（画布 · 浮层 · 药丸）

> 一句话：**浅灰画布上浮起白色面板，面板里是黑字与胶囊控件。** 把边框留给结构与状态，把颜色留给数据，把药丸留给操作。

## 1. 设计语言

| 原则 | 落地 |
|---|---|
| 画布与浮层 | 画布 `#F2F2F4`，三块面板 `#FFFFFF`，间距 10px，1px `--line` 描边 + 14px 圆角；不用投影 |
| 黑字三级 | 主文 `#161618`、次文 `#606067`、辅助 `#94949B`；层级靠字号与灰度，不靠彩色 |
| 药丸 = 操作 | 按钮、URL 大胶囊、Toast、下拉选项使用 `999px` 药丸，是"可点"的统一信号 |
| 文本 Tab | 编辑区与响应视图用无圆角下划线 Tab，避免成排描边胶囊造成视觉噪音 |
| 色块徽章 | 方法/状态用 6px 色块 Tag：软底 + 同色深字，无描边；状态色不用于装饰 |
| 单一强调色 | 黑色即强调色。主操作 = 墨底白字，其余操作 = 浅底或无底 |
| 字号克制 | 全局只用 12 / 13 / 14 / 20 四档 |
| 图标线性 | 1.5px 线性图标（stroke），不填充 |

## 2. 设计变量（tokens.css 唯一事实源）

```css
:root {
  /* 色彩 */
  --bg: #FFFFFF;          /* 浮层面板 */
  --bg-canvas: #F2F2F4;   /* 应用画布 */
  --bg-subtle: #F6F6F7;   /* 填充输入 / 次级面 */
  --bg-hover: #F0F0F2;
  --bg-active: #E8E8EC;
  --ink: #161618;
  --ink-secondary: #606067;
  --ink-tertiary: #94949B;
  --line: #E5E5E8;
  --line-strong: #D4D4D9;
  /* 状态色（字 + 软底，仅用于状态） */
  --ok: #0A7F37;     --ok-soft: #E7F4EC;
  --warn: #B45309;   --warn-soft: #FBF0E2;
  --err: #C81E1E;    --err-soft: #FBEAEA;
  --info: #1D4ED8;   --info-soft: #E9EEFC;
  --violet: #7C3AED; --violet-soft: #F1EBFD;
  /* 形状 */
  --radius-pill: 999px;     /* 操作类控件 */
  --radius-panel: 14px;     /* 浮层面板 / 对话框 */
  --radius-control: 8px;    /* 输入框、树行、窗口控制、命令项 */
  --radius-chip: 6px;       /* 方法/状态徽章、菜单项 */
  --gap-panel: 10px;        /* 画布间距，也是分栏拖拽热区 */
  /* 字 */
  --font-ui: 13px/1.5 -apple-system, "Segoe UI Variable Text", "Segoe UI", "PingFang SC", "Microsoft YaHei", sans-serif;
  --font-mono: 12.5px/1.65 "JetBrains Mono", "Cascadia Code", Consolas, monospace;
  /* 节奏 */
  --sp-1: 4px; --sp-2: 8px; --sp-3: 12px; --sp-4: 16px; --sp-6: 24px;
  --h-pill: 30px;         /* 药丸控件标准高 */
  --h-pill-lg: 36px;      /* 主按钮 / 发送 */
}
```

暗色模式：MVP 不做；若做，反转 `--bg/--bg-canvas/--bg-subtle/--ink/--line` 系变量，状态色与软底按暗色重新取色。

## 3. 组件规范

### 3.1 按钮与圆角策略
| 类型 | 样式 | 用途 |
|---|---|---|
| Primary | 墨底白字，h=36，padding 0 18px，hover `#333336`，药丸 | 发送、Runner 启动 |
| Secondary | `--bg-subtle` 填充、无边框、药丸，hover `--bg-active` | 保存、普通操作 |
| Ghost | 无底无边框，hover `--bg-hover`，药丸 | 树节点操作、工具栏 |
| Danger | `--err` 字 + `--err-soft` 软底，药丸 | 删除、取消请求 |

所有按钮：禁用态 `opacity:.4` 且 `cursor:not-allowed`，聚焦态 2px 外描边 `--ink`（offset 2px），`title` 必写。

圆角只允许落在以下档位，`verify-flow` 按此策略逐按钮断言：

| 元素 | 圆角 |
|---|---|
| 按钮 / URL 胶囊 / Toast / 下拉选项 | `999px` |
| 浮层面板 / 对话框 / 命令面板 | `14px` |
| 输入框 / 树行 / 窗口控制 / 命令项 | `8px` |
| 方法/状态徽章 / 右键菜单项 / 状态栏紧凑控件 | `6px` |
| 文本 Tab | `0`（下划线指示） |
| 右键菜单 / 下拉弹层 | `10px` |

### 3.2 HTTP 方法与状态徽章（色块 Tag，无描边）
| 方法 | 字色 | 底色 |
|---|---|---|
| GET | `--ok` | `--ok-soft` |
| POST | `--info` | `--info-soft` |
| PUT | `--warn` | `--warn-soft` |
| DELETE | `--err` | `--err-soft` |
| PATCH | `--violet` | `--violet-soft` |
| 其他 | `--ink-secondary` | `--bg-subtle` |

规则：高 20px、最小宽 44px、padding 0 6px、字号 12/700、6px 圆角。状态码复用同一套软底色块（2xx 绿 / 4xx 橙 / 5xx 红），出现在响应状态行与历史行。方法色与状态色是**全应用唯一允许的彩色文字**。

### 3.3 输入框
- 高 32px，8px 圆角，`--bg-subtle` 填充，1px 透明边框；hover 不变，聚焦时边框变 `--ink`、底变白（不发光、不阴影）。
- URL 大胶囊：高 44px、药丸、`--bg-subtle` 填充，内边距 4px；左侧方法选择高 34px（软底色块），右侧发送药丸高 36px。聚焦时整颗胶囊描边 `--ink`、底变白。
- **大胶囊独占一行**：接口名与保存按钮放在其上方的标题行（名称 20px/600，无边框，hover/focus 才显底）。三者挤在同一行会把 URL 压到不可用宽度。
- **窄容器自适应**（容器查询，不是窗口宽度）：编辑面板 ≤480px 时左右内边距降为 8px、方法选择 padding 10px、发送按钮收成 36px 图标圆钮；此时 1024 最小窗口下 URL 输入仍 ≥200px（实测 237px）。
- 下拉列表使用 Chromium `appearance: base-select` 定制：白底、1px `--line`、圆角 10px、无阴影；选项高 28px、药丸圆角，hover `--bg-hover`，选中黑底白字；箭头展开时旋转 180°。
- 回归护栏：`scripts/verify-flow.mjs` 断言 URL 输入框 ≥200px，并在 `Emulation` 1024×640 下复测；展开下拉后断言弹层 10px、无阴影、选项 999px。

### 3.4 项目树
- 行高 32px，左右外边距 6px，8px 圆角；hover `--bg-hover`；选中 `--bg-active`，不加左侧黑条、不加粗（500）。
- 层级缩进 14px/级；接口行前置方法徽章（44px）；行尾操作按钮高 22px，默认隐藏，hover/选中行出现。
- 拖拽排序：拖到目标行上沿=插前、下沿=插后，插入位显示 2px 黑线；拖入集合时显示虚线描边。集合可拖入项目根，接口只在同项目/同集合内移动。落库走 `tree:move` 的中点 `sortOrder`，重启后顺序不变。
- 右键菜单：白底 1px 边框圆角 10px，无阴影，项高 30px / 6px 圆角，危险项红字。项目菜单=新建集合/新建接口/导入 Postman…/导出为 Postman Collection…/重命名项目/删除项目；集合菜单=新建接口/运行集合/重命名集合/删除集合；接口菜单=打开/复制接口/重命名接口/删除接口。
- 重命名走 `RenameDialog`（复用 §5 对话框样式）：单行 `.field` 输入框自动全选聚焦、`Enter` 提交、`Esc` 或点遮罩取消；名称为空或与原名相同时静默关闭不发请求；成功后 Toast「已重命名为「X」」并刷新树。重命名当前打开的接口只同步编辑器草稿，不重新拉取接口，避免冲掉未保存改动。接口名与 URL 相互独立 —— 单独改名不影响 URL、方法与环境变量。
- 树工具栏（新建项目输入框右侧）固定一枚 `upload` 图标按钮，`title="导入 Postman Collection / Environment"`，点击打开 §3.7 导入对话框；环境导入/导出入口在底栏环境选择器两侧（见 §4）。
- 删除必须走确认对话框：文案含受影响数量（见 §5），默认焦点在「取消」，`Esc` 取消。
- 空列表：浅底圆角空态，一行说明 + 一枚添加药丸（`kv-empty`），不画插画。

### 3.5 Tab / 分段控件
- **文本 Tab**：无容器、无圆角、13px；选中项 `--ink` + 600 + 2px 墨色下划线，指示线压在容器分隔线上。用于编辑区 Params/Headers/Auth/伪装/Body/提取器/脚本 与响应 Pretty/Raw/Headers/历史。编辑面板 ≤480px 时 padding 6px、字号 12px，保证 1024 下七个 Tab 完整可见。
- **药丸分段控件**：`--bg-subtle` 轨道、3px padding、药丸圆角；选中项墨底白字。用于「响应 / Runner」二级面板切换。
- 响应头部在容器 ≤430px 时允许换行：状态行落到第二行，避免状态数字被裁切。

### 3.6 响应面板
- 头部高 48px，左侧文本 Tab，右侧状态行：状态码软底色块 + `200 OK · 143ms · 2.4KB` 等宽数字（`tabular-nums`）。
- Body 区：16px 内边距、等宽字体 12.5px/1.65，JSON 语法高亮只着 `--ink`（key）、`--info`（string）、`--warn`（number/bool），克制用色。
- 断言结果：通过项为 SVG check 图标（`--ok` 描边）+ 黑字断言名；失败项为 SVG cross 图标（`--err` 描边）+ 红字错误摘要；`pm.test.skip` 的跳过项为 SVG dash 图标 + 三级辅助色文字并标注「断言跳过」，不参与失败判定；三种状态均无卡片无底色块。
- 提取变量：横向排列的 6px 中性色块 Tag。
- Runner 数据驱动：明细面板顶部一块「数据行」区 —— `.field` 标签 + 等宽 textarea（3 行起）粘贴 CSV/JSON，右侧 `ghost` 药丸「解析」「清空」（全 SVG 图标），再一个 `迭代次数` 数字输入（留空 = 跟随行数），最右 12px 辅助色文本给出「CSV · 3 行 · 迭代 3 次」或解析错误；无底色块、无外框分割线以外的装饰。树与命令面板发起的运行自动带上这块数据源。
- Runner 数据驱动：迭代数 > 1 时，明细行在状态图标后加三级辅助色文字「第 N/M 轮」（纯文字，无底色块、无图标），面板标题行同步显示「M 轮迭代」；单轮运行不出现任何轮次文案。左侧运行记录的 `通过/计划` 计数按 `接口数 × 迭代数` 统计。
- 历史面板：行高固定 32px，按「今天 / 昨天 / YYYY-MM-DD」分组；搜索框过滤 URL/方法/状态码；万条记录用虚拟滚动（overscan 4 行、只渲染可视区±4 行），首屏骨架屏 6 行；底部「加载更多」按 `cursor` 续拉（每页 200 条），末页显示「共 N 条」。

### 3.7 对话框（Postman 导入）

- 结构：遮罩 + 白卡 580px、14px 圆角、1px `--line`、无阴影；内边距 20px、纵向间距 12px；标题「导入 Postman 资产」，说明一行 12px 辅助色；`Esc` 与点击遮罩关闭。
- 来源：隐藏 `<input type="file" accept=".json,application/json">` + 药丸按钮「选择文件」（`upload` 图标，14px），右侧文件名 12px 辅助色、超长省略显示「未选择文件」；下方等宽 12px 文本域可直接粘贴 JSON（min 140px / max 260px，聚焦 1px 墨色边框）。
- 识别：输入停止 350ms 后自动调用 `postman:inspect` 预览，类型（Collection / Environment）以 20px 灰底药丸标注；名称 13px/600 截断；计数行 12px：集合 / 接口 / 变量 / 脚本。
- 提示：`warnings` 列表最多展示 6 条（`路径 + 说明`，12px），超出折叠为「还有 N 条提示」；失败时红字 `alert` 图标 + 一行原因，无弹窗叠加。
- 方式：Collection 为单选「新建项目 / 导入到「当前项目名」」（无活动项目时后者禁用并降透明度）；Environment 为「同名环境覆盖变量」复选框，且未选择项目时禁用导入并提示「环境需要归属项目」。
- 按钮：右对齐「取消 / 导入」，导入中按钮文案变「导入中…」并禁用；成功后关闭对话框，Toast 显示导入摘要与导出路径（见 §5）。
- 导入报告：返回 `warnings` 非空时不关闭对话框，切换为标题「导入报告」——摘要行「导入完成：N 集合 · M 接口 · K 变量 · W 条提示」，下方可滚动提示列表（最大 240px），底部单枚「完成」按钮；无提示时直接关闭并只留 Toast。

### 3.7b 对话框（.tapi 导入）

- 结构与 §3.7 一致（遮罩 + 580px 白卡、14px 圆角、1px 线、无阴影），标题「导入 .tapi 项目」，说明一行点明「历史 / Runner 结果 / Cookie 不随文件传递」。
- 入口：项目右键 `导入 .tapi…`、集合右键 `导出该集合为 .tapi…`、项目右键 `导出为 .tapi…`；导出走主进程保存对话框（`tapi` / `json` 过滤器），取消静默不弹 Toast。
- 选文件或粘贴二选一（与 §3.7 同控件形态，`accept=".tapi,application/json"`）；预览为**两列纯文字 `dl`**（项目 / 来源版本 / 格式 / 内容计数 / 校验和 / 敏感变量），无卡片无底色块，长值省略号 + `title` 全文。
- 策略区用 `.segmented` 药丸分段：导入方式（新建项目 / 合并进现有项目）与判重命中（跳过 / 覆盖 / 保留两份）；合并时显示目标项目下拉与一行说明文案。
- `checksumOk=false` 或 `supported=false` 时红色 12px 提示并禁用「导入」按钮，绝不给「强行导入」的出口；`redactedCount>0` 在预览里写明「导入后需自行填写」。
- 导入成功 Toast：`导入完成：N 集合 · M 接口 · 跳过 K`，有提示时追加 `· W 条提示`。

### 3.8 图标系统（强制）

**全部图标必须是内联 SVG，严禁使用 emoji 充当图标**（含树节点、状态标记、按钮、Toast、空态）。

```html
<!-- 唯一图标写法：内联 SVG，currentColor 继承文字色 -->
<svg class="icon" viewBox="0 0 24 24" fill="none" stroke="currentColor"
     stroke-width="1.5" stroke-linecap="round" stroke-linejoin="round"
     width="16" height="16" aria-hidden="true">
  <path d="M4 12.5l5 5L20 6.5"/>  <!-- check -->
</svg>
```

| 规则 | 说明 |
|---|---|
| 来源 | 图标库存于 `src/components/Icon.tsx`，构建期注册为组件；禁止外链 iconfont/图片图标 |
| 规格 | viewBox `0 0 24 24`，stroke 1.5px，round 线帽；尺寸仅 14 / 16 / 20 三档 |
| 着色 | 一律 `currentColor`，颜色由父级文字色决定，SVG 内不写死颜色 |
| 状态标记 | 通过=check、失败=cross、跳过=dash、运行中=spinner（CSS 旋转，不用 GIF） |
| 语义 | 装饰性图标 `aria-hidden="true"`；功能性图标配 `aria-label` 或相邻文字 |
| emoji | UI 任何位置不出现 emoji；文档、断言名、变量值中用户自输入的 emoji 原样展示但 UI 不主动渲染为图标 |
| 品牌 LOGO | `src/assets/logo.png`（透明底位图）仅用于标题栏品牌位与窗口/安装包图标，不属于图标系统，不得替代任何功能性图标 |

### 3.9 状态与反馈
- Toast：**底部居中**黑底白字药丸，距窗口底 44px（浮在 30px 状态栏上方），2s 消失；成功/失败前缀 SVG check/cross 图标（currentColor）。
- 空态：浅底圆角块内一行 `--ink-tertiary` 说明 + 一枚药丸操作；响应区空态用居中一行字 + Ghost 操作。
- 加载：12px SVG 细线圆环（2px 黑弧，CSS 旋转），不用骨架屏（除历史列表）。
- 开放调用授权条（11 号文档 §7）：底部居中浮层，位于 Toast 之上（距底 96px），白底 1px `--line` 圆角 14px、无阴影；左侧标题 + 一行事由 + 「查看说明书摘要」药丸（展开 `--bg-subtle` 等宽块），右侧「拒绝」（`danger`）与「允许」（`primary`）两枚药丸；60s 无操作按拒绝自动消失。同时只展示最早一条。
- 开放调用设置面板：复用对话框样式（580px 白卡），分组用 1px `--line` 上边框 + 12px 辅助色小标题；「监听地址」用 `.segmented` 两枚（仅本机 / 局域网），局域网未勾二次确认前禁用；新密码只在「生成」后出现在一条等宽块里，点「已记录」即清空，界面任何位置不回显已存密码。

## 4. 布局

```
┌────────────────────────────────────────────────────────────────────┐
│ ● ToAPI │ 项目 / 接口                              ─  □  ✕        │ 46px，整条可拖拽
│ ┌──────────┐  ┌────────────────────────────┐  ┌─────────────────┐ │
│ │ 新建项目  │  │ 接口名（20px）        保存  │  │ 响应 / Runner   │ │
│ │ ──────── │  │ URL 大胶囊（44px 独占一行） │  │ ─────────────── │ │
│ │ 项目树    │  │ Params Headers Auth …      │  │ Pretty Raw …    │ │
│ │ 240px    │  │ 下划线 Tab                 │  │ 45% 宽，可切换   │ │
│ │ 可拖拽    │  │                            │  │ 上下 / 左右      │ │
│ └──────────┘  └────────────────────────────┘  └─────────────────┘ │
│  画布 10px 间距 · 浮层白卡 14px 圆角 · 1px 描边                      │
├────────────────────────────────────────────────────────────────────┤
│ 环境 无 ⇧ ⇩   {{ baseUrl }} [值]            DB 4.0 KB      v0.1.5  │ 30px，画布底
└────────────────────────────────────────────────────────────────────┘
```

- **画布**：`--bg-canvas` 铺满窗口；`.shell` 左右与底部留白 10px，三块面板之间 10px 间距（即拖拽热区），面板白底、1px `--line`、14px 圆角、无投影。
- **一体化标题栏（Windows）**：`frame:false` 无边框窗口，网页从窗口第一像素开始；标题栏 46px、画布同色、无下边框，整条 `-webkit-app-region: drag`，右侧窗口控件 `no-drag`。品牌区 = 26px 品牌位内嵌 24px 透明底 LOGO（`src/assets/logo.png`，手写 `TA.`）+ `ToAPI`（13px/600）；其后是 12px 面包屑「项目 / 接口」，辅助色、可省略，≤900px 隐藏。窗口与安装包图标由同一 LOGO 生成（`build/icon.png` 512×512、`electron/assets/icon.png` 256×256）。
- 窗口控件为三枚 32×28px、8px 圆角的无底按钮（chrome 例外，见 §3.1 圆角策略），图标 14px/1.5px/currentColor：最小化 `minus`、最大化 `maximize` / 还原 `restore`、关闭 `cross`。hover 为 7% 墨色底，关闭 hover 为 `--err` 底白字；每个按钮必须有 `title`（最小化 / 最大化 / 还原 / 关闭 (Alt+F4)）与 `aria-label`。
- 最大化图标由 `window:get-state` 初始化、`event:window-state` 驱动，双击拖拽区、`Win+↑`、贴边等系统路径同样同步。Linux/信创按 14 号文档保留系统原生窗口装饰，不渲染自绘标题栏。
- Toast 固定在窗口底部居中（bottom 44px），不与标题栏、保存按钮争夺顶部空间。
- 三栏均可拖拽调宽，树最小 180px、默认 240px；响应默认 45% 宽。
- 底栏环境区：环境下拉右侧紧接两枚 20px 高图标按钮——`upload` 打开 Postman 导入对话框，`download` 导出当前环境（无活动环境时禁用）；底栏控件统一 22px 高、6px 圆角的 Ghost chip，只有图标与 `title`。
- 分屏模式：响应面板可切到编辑器下方（垂直堆叠），默认左右分屏；记住用户选择。上下分屏时响应默认占下半区 45%，上下分隔条同样可拖。
- 分隔条命中区 10px（画布间距本身），视觉为 3px×32px 胶囊把手，仅 hover/拖拽时显示；支持聚焦后用方向键 ±16px（Shift ±48px）调节。
- 偏好持久化（`localStorage`，前缀 `toapi.ui.`）：`treeWidth`（默认 240）、`rightRatio`（默认 0.45）、`bottomRatio`（默认 0.45）、`orientation`（`"right"` / `"bottom"`）。重启后布局与分屏方向不变。
- 最小窗口 1024×640：面板不重叠、文本 Tab 完整、URL ≥200px；响应头部按容器宽度换行。

## 5. 文案与交互细则

- 全中文界面，技术词保留英文（Headers、Runner、cURL）。
- 危险操作二次确认文案格式：「删除项目 X？其下 N 个集合、M 个接口将一并删除，历史保留。」+ 黑字「取消」/ 红字「删除」。集合/接口同理：`删除集合「X」？其下 N 个接口将一并删除，历史保留。`、`删除接口「X」？删除后不可恢复，历史保留。`
- 快捷键全部可悬浮提示：
  - `Ctrl+Enter` 发送 · `Ctrl+S` 保存 · `Ctrl+K` 命令面板 · `Ctrl+`` 切换响应面板方向 · `Ctrl+Shift+R` 运行当前集合
- 命令面板（`Ctrl+K`）= 全局搜索入口：一条命令列表同时覆盖**项目 / 接口 / 集合 / 环境 / 动作**，无需先选项目（跨项目可搜可跳）。输入即过滤，匹配范围含接口名称、方法、**URL**、项目/集合路径与动作提示；结果行左侧类型图标（项目 `folder`、接口 `doc`、运行 `send`、环境 `refresh`、面板 `panel`，全 SVG），右侧依次为说明（项目 / 集合 / URL）与快捷键 `kbd`。`↑/↓` 选择、`Enter` 执行、`Esc` 关闭；命中接口时先切项目再打开，保证右侧面板状态一致。空查询列全部，无匹配显示「没有匹配项」。
- Toast 底部居中不遮挡主操作：距窗口底 44px，圆角 999px，2s 自动消失；成功=`check`，失败=`cross`。
- Postman 导入/导出文案：导入成功=`导入完成：N 集合 · M 接口 · K 变量`，存在提示时追加 `· W 条提示`；导出成功=`已导出到 <路径>`；用户取消保存对话框静默，不弹 Toast。

## 6. 反模式（禁止清单）

- 禁止：渐变、玻璃拟态、卡片投影、紫色/蓝色大色块
- 禁止：彩色图标、插画空态、吉祥物（方法/状态软底色块例外）
- 禁止：emoji 充当图标或状态标记（一律 SVG，见 §3.8）
- 禁止：超过 4 档字号、超过 2 种字体
- 禁止：脱离 §3.1 圆角档位的控件；禁止用描边胶囊堆满界面（Tab 用下划线，输入用填充）
- 禁止：无快捷键提示的按钮（title 属性必写）
