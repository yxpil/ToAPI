# ToAPI — UI 设计规范（药丸 · 白底 · 黑字）

> 一句话：**白纸黑字，万物皆药丸。** 界面像一张排印精良的纸，控件是纸上的胶囊。

## 1. 设计语言

| 原则 | 落地 |
|---|---|
| 白底黑字 | 页面底 `#FFFFFF`，面板底 `#FAFAFA`，正文 `#111111`。除状态色外不出现第三种彩色 |
| 药丸形 | 所有可点控件（按钮、Tab、Tag、方法徽章、输入框组）圆角 `999px` |
| 细线分隔 | 分割线 `#E5E5E5` 1px，不用卡片投影 |
| 单一强调色 | 黑色即强调色。主按钮 = 黑底白字药丸 |
| 字号克制 | 全局只用 12 / 13 / 14 / 20 四档 |
| 图标线性 | 1.5px 线性图标（stroke），不填充 |

## 2. 设计变量（tokens.css 唯一事实源）

```css
:root {
  /* 色彩 */
  --bg: #FFFFFF;
  --bg-subtle: #FAFAFA;
  --bg-hover: #F3F3F3;
  --bg-active: #EBEBEB;
  --ink: #111111;
  --ink-secondary: #6B6B6B;
  --ink-tertiary: #9E9E9E;
  --line: #E5E5E5;
  /* 状态色（仅用于状态，不用于装饰） */
  --ok: #0A7F37;
  --warn: #B45309;
  --err: #C81E1E;
  --info: #1D4ED8;
  /* 形状 */
  --radius-pill: 999px;
  --radius-panel: 12px;   /* 仅用于非交互容器：编辑器卡片、响应面板 */
  /* 字 */
  --font-ui: 13px/1.5 -apple-system, "Segoe UI", "PingFang SC", "Microsoft YaHei", sans-serif;
  --font-mono: 12.5px/1.6 "JetBrains Mono", "Cascadia Code", Consolas, monospace;
  /* 节奏 */
  --sp-1: 4px; --sp-2: 8px; --sp-3: 12px; --sp-4: 16px; --sp-6: 24px;
  --h-pill: 30px;         /* 药丸控件标准高 */
  --h-pill-lg: 36px;      /* 主按钮 */
}
```

暗色模式：MVP 不做；若做，仅反转 `--bg/--ink/--line` 系变量，状态色不变。

## 3. 组件规范

### 3.1 按钮
| 类型 | 样式 | 用途 |
|---|---|---|
| Primary | 黑底 `#111` 白字，h=36，padding 0 18px，hover 变 `#333` | 发送、Runner 启动 |
| Secondary | 白底黑字 1px 边框 `--line`，hover `--bg-hover` | 保存、普通操作 |
| Ghost | 无边框，hover `--bg-hover` | 树节点操作、工具栏 |
| Danger | 白底 `--err` 字与边框 | 删除、清空 |

所有按钮：`border-radius: var(--radius-pill)`，禁用态 `opacity:.4` 且 `cursor:not-allowed`，聚焦态 2px 外描边 `--ink`（offset 2px）。

### 3.2 HTTP 方法徽章（药丸 Tag，白底彩字描边）
| 方法 | 字色 |
|---|---|
| GET | `--ok` |
| POST | `--info` |
| PUT | `--warn` |
| DELETE | `--err` |
| PATCH | `#7C3AED` |
| 其他 | `--ink-secondary` |

规则：方法色是**全应用唯一允许的彩色文字**，仅出现在方法徽章与历史列表方法列。

### 3.3 输入框
- 高 30px，药丸圆角，1px `--line` 边框，聚焦时边框变 `--ink`（不发光、不阴影）。
- URL 大输入条例外：高 40px，左侧内嵌方法选择药丸，右侧内嵌发送按钮，整体是一个"大胶囊"。
- **大胶囊独占一行**：接口名与保存按钮放在其上方的标题行（名称为无边框标题式输入，hover/focus 才显形）。三者挤在同一行会把 URL 字段压到不可用宽度（实测 4px），这是本条规则的由来。
- 窄窗口（≤1180px）左右内边距降为 8px，保证 1024 最小窗口下 URL 输入仍 ≥200px（实测 241px）。
- 下拉列表使用 Chromium `appearance: base-select` 定制，不再用系统直角弹层：白底、1px `--line`、圆角 10px、无阴影；选项高 28px、药丸圆角，hover `--bg-hover`，选中黑底白字；箭头在展开时旋转 180°。
- 回归护栏：`scripts/verify-flow.mjs` 断言 URL 输入框宽度 ≥ 200px，并在 `Emulation` 1024×640 下复测；同时展开下拉列表，断言弹层 10px、无阴影、选项 999px。

### 3.4 项目树
- 行高 30px，hover `--bg-hover`，选中 `--bg-active` + 左侧 2px 黑条。
- 层级缩进 14px/级；接口行前置方法徽章（小号，宽 44px 居中）。
- 行尾操作按钮高 22px，默认隐藏、hover/选中行时出现（运行集合、删除等）。
- 拖拽排序：拖到目标行上沿=插前、下沿=插后，插入位显示 2px 黑线；集合可拖入项目根，接口只在同项目/同集合内移动。落库走 `tree:move` 的中点 `sortOrder`，重启后顺序不变。
- 右键菜单：白底 1px 边框圆角 10px，无阴影，危险项红字。项目菜单=新建集合/新建接口/删除项目；集合菜单=新建接口/运行集合/删除集合；接口菜单=打开/复制接口/删除接口。
- 删除必须走确认对话框：文案含受影响数量（见 §5），默认焦点在「取消」，`Esc` 取消。

### 3.5 Tab / 分段控件
- 药丸容器（`--bg-subtle` 底，padding 3px），选中项白底黑字小药丸。
- 用于：Params/Headers/Body/Scripts 切换、响应 Pretty/Raw/Headers 切换。

### 3.6 响应面板
- 状态行：`200 OK · 143ms · 2.4KB` 等宽数字（`font-variant-numeric: tabular-nums`），状态码 2xx 绿 / 4xx 橙 / 5xx 红。
- Body 区：等宽字体，JSON 语法高亮只着 `--ink`（key）、`--info`（string）、`--warn`（number/bool），克制用色。
- 断言结果：通过项为 SVG check 图标（`--ok` 描边）+ 黑字断言名；失败项为 SVG cross 图标（`--err` 描边）+ 红字错误摘要列表，无卡片无底色块。
- 历史面板：行高固定 32px，按「今天 / 昨天 / YYYY-MM-DD」分组；搜索框过滤 URL/方法/状态码；万条记录用虚拟滚动（overscan 4 行、只渲染可视区±4 行），首屏骨架屏 3 行；底部「加载更多」按 `cursor` 续拉（每页 200 条），末页显示「共 N 条」。

### 3.8 图标系统（强制）

**全部图标必须是内联 SVG，严禁使用 emoji 充当图标**（含树节点、状态标记、按钮、Toast、空态）。

```html
<!-- 唯一图标写法：内联 SVG，currentColor 继承文字色 -->
<svg class="icon" viewBox="0 0 24 24" fill="none" stroke="currentColor"
     stroke-width="1.5" stroke-linecap="round" stroke-linejoin="round"
     width="16" height="16" aria-hidden="true">
  <path d="M4 12.5l5 5L20 6.5"/>  <!-- check -->
</svg>
```

| 规则 | 说明 |
|---|---|
| 来源 | 图标库存于 `src/assets/icons/*.svg`，构建期注册为组件；禁止外链 iconfont/图片图标 |
| 规格 | viewBox `0 0 24 24`，stroke 1.5px，round 线帽；尺寸仅 14 / 16 / 20 三档 |
| 着色 | 一律 `currentColor`，颜色由父级文字色决定，SVG 内不写死颜色 |
| 状态标记 | 通过=check、失败=cross、跳过=dash、运行中=spinner（SVG SMIL/CSS 旋转，不用 GIF） |
| 语义 | 装饰性图标 `aria-hidden="true"`；功能性图标配 `aria-label` 或相邻文字 |
| emoji | UI 任何位置不出现 emoji；文档、断言名、变量值中用户自输入的 emoji 原样展示但 UI 不主动渲染为图标 |

### 3.9 状态与反馈
- Toast：顶部居中黑底白字药丸，2s 消失；成功/失败前缀 SVG check/cross 图标（currentColor）。
- 空态：一行 `--ink-tertiary` 小字 + 一个 Ghost 按钮，不画插画。
- 加载：12px SVG 细线圆环（2px 黑弧，CSS 旋转），不用骨架屏（除历史列表）。

## 4. 布局

```
┌──────────┬───────────────────────────┬──────────────────┐
│  项目树   │  接口名（标题行）··· 保存   │ 响应 / Runner 切换│
│  240px   ├───────────────────────────┤                  │
│  可拖拽   │  URL 大胶囊（独占一行）    │    45% 宽         │
│  调宽     ├───────────────────────────┤    可切换上下/左右 │
│          │  编辑器 Tab                │                  │
│          │  (Params/Headers/Auth/     │                  │
│          │   伪装/Body/提取器/脚本)    │                  │
└──────────┴───────────────────────────┴──────────────────┘
底栏 22px：当前环境名（点击切换） · DB 大小 · 版本号
```

- 三栏均可拖拽调宽，树最小 180px、默认 240px；响应默认 45% 宽。
- 分屏模式：响应面板可切到编辑器下方（垂直堆叠），默认左右分屏；记住用户选择。上下分屏时响应默认占下半区 45%，上下分隔条同样可拖。
- 分隔条命中区 6px、视觉 1px 细线，hover/拖拽时线变 `--ink`；支持聚焦后用方向键 ±16px（Shift ±48px）调节。
- 偏好持久化（`localStorage`，前缀 `toapi.ui.`）：`treeWidth`（默认 240）、`rightRatio`（默认 0.45）、`bottomRatio`（默认 0.45）、`orientation`（`"right"` / `"bottom"`）。重启后布局与分屏方向不变。

## 5. 文案与交互细则

- 全中文界面，技术词保留英文（Headers、Runner、cURL）。
- 危险操作二次确认文案格式：「删除项目 X？其下 N 个集合、M 个接口将一并删除，历史保留。」+ 黑字「取消」/ 红字「删除」。集合/接口同理：`删除集合「X」？其下 N 个接口将一并删除，历史保留。`、`删除接口「X」？删除后不可恢复，历史保留。`
- 快捷键全部可悬浮提示：
  - `Ctrl+Enter` 发送 · `Ctrl+S` 保存 · `Ctrl+K` 命令面板 · `Ctrl+`` 切换响应面板方向 · `Ctrl+Shift+R` 运行当前集合
- 命令面板：白底、圆角 12px、无阴影；输入即过滤（匹配名称/提示/说明），`↑/↓` 选择、`Enter` 执行、`Esc` 关闭；底部显示快捷键提示。
- Toast 居中不遮挡主操作：距窗口顶 16px，圆角 999px，2s 自动消失；成功=`check`，失败=`cross`。

## 6. 反模式（禁止清单）

- 禁止：渐变、玻璃拟态、卡片投影、紫色/蓝色大色块
- 禁止：彩色图标、插画空态、吉祥物
- 禁止：emoji 充当图标或状态标记（一律 SVG，见 §3.8）
- 禁止：超过 4 档字号、超过 2 种字体
- 禁止：圆角在 4~20px 之间的交互控件（要么药丸 999px，要么面板 12px）
- 禁止：无快捷键提示的按钮（title 属性必写）
